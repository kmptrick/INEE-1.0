# Plan Comptable Minimum Normalisé (PCMN) — Belgique

> Base : **A.R. du 21 octobre 2018** (exécution de l'art. III.84 du Code de droit économique).
> « Minimum normalisé » = socle obligatoire et uniforme, extensible en sous-comptes.
> Codification décimale. 7 classes : **1 à 5 = bilan**, **6-7 = compte de résultats**,
> **classe 0 = droits et engagements hors bilan**.
