# Plan Comptable Normalisé (PCN) — Luxembourg

> Base : **loi modifiée du 19 décembre 2002** ; structure fixée par le **règlement
> grand-ducal du 12 septembre 2019** (PCN 2020, en vigueur pour les exercices ouverts
> à compter du 1ᵉʳ janvier 2020). Aligné sur la collecte électronique **eCDF**.
> **Chaque compte est identifié par un code à 5 chiffres.**
> 7 classes : **1 à 5 = bilan**, **6-7 = compte de profits et pertes**.
>
> ⚠️ Spécificité luxembourgeoise : les **dettes financières** et les **provisions** figurent
> en **classe 1** (et non dans les tiers). Les rubriques ci-dessous sont les têtes de
> chapitre (2 chiffres) ; pour les codes exhaustifs à 5 chiffres, se référer au PCN officiel
> (eCDF / CNC.lu, versions publiées KPMG/EY).
